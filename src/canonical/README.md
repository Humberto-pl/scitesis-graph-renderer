# Canonical presentation registry

This registry is a local, read-only semantic presentation reference for the SciTesis Conceptual Simulator v0.3 canon. The simulator artifact remains the authority for every instance: its entities, relations, identifiers, endpoints, canonical names, and metadata are preserved.

The registry is neither a validator nor a transformer. A lookup cannot create, remove, repair, normalize, or reject graph content. QUALIS is a regression fixture, not the ontology source. Where the normative documents are unavailable locally, an entry intentionally omits semantics not stated explicitly by the PR4 requirements rather than inferring them from QUALIS or legacy graph kinds.
